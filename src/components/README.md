# UI Component Packages

## Overview
Houses all modular React presentation, layout, modal, and analytical UI components organized by domain sub-systems (cattle inventory, production, reproduction, health, zootechnics, finance, multi-farm administration, navigation, and hardware simulation).

## Subdirectories & Boundaries
- [ai](./ai/README.md) - Conversational AI cattle advisory assistant dialog.
- [alerts](./alerts/README.md) - Unified smart alerts center for withdrawals, dry-offs, and calvings.
- [animals](./animals/README.md) - Livestock inventory tables, photo grids, detail cards, and stage transitions.
- [backup](./backup/README.md) - Database snapshot generation and atomic restoration dialogs.
- [bulk](./bulk/README.md) - Excel spreadsheet parser and batch cattle importer.
- [farms](./farms/README.md) - Multi-hacienda property registration and configuration dialogs.
- [finance](./finance/README.md) - Cost-per-liter economics, operational P&L ledgers, and investor portfolio valuation.
- [health](./health/README.md) - Veterinary treatments, dosages, routes, and food safety withdrawal monitors.
- [layout](./layout/README.md) - Responsive top navigation bar, desktop sidebar, and mobile touch tab bar.
- [onboarding](./onboarding/README.md) - Pilot tester welcome modals and initial herd setup choices.
- [production](./production/README.md) - Daily AM/PM milking ledgers, bulk milk tanks, and scale weighing logs.
- [reproduction](./reproduction/README.md) - Breeding services, palpation checks, calving timelines, and dry-off therapy.
- [roles](./roles/README.md) - Contextual user persona banners (Admin, Zootechnician, Investor, Veterinarian, Worker).
- [scanner](./scanner/README.md) - Universal chip reader supporting Web NFC, camera barcodes/QR, and Bluetooth wands.
- [share](./share/README.md) - Peer evaluation sharing, QR code generator, and WhatsApp diagnostic feedback.
- [testing](./testing/README.md) - Physical smartphone frame emulator, rural signal simulator, and QA diagnostic harness.
- [zootechnician](./zootechnician/README.md) - Daily weight gain rankings (ADG), lactation curve persistency, and body condition scoring.
